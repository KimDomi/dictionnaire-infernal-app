# Dictionnaire Infernal App (지옥사전 앱)

자크 콜랭 드 플랑시(Jacques Collin de Plancy, 1794–1881)의 오컬트·악마학 백과사전 **『지옥사전(*Dictionnaire Infernal*)』**을 기반으로 한 애플리케이션 저장소입니다.

## 리소스 (`resources/`)

퍼블릭 도메인(Public Domain)으로 공개된 1863년 제6판(루이 브르통 삽화 수록본) 원본 PDF 및 OCR 텍스트 리소스가 [`resources/`](./resources/) 디렉터리에 포함되어 있습니다.

- `resources/dictionnaire_infernal_1863_full.pdf`: 1863년 제6판 전체 스캔본 PDF (736쪽, 루이 브르통 삽화 포함)
- `resources/dictionnaire_infernal_illustrations.pdf`: 『지옥사전』 주요 악마 삽화 발췌 PDF (62쪽, 경량 버전)
- `resources/dictionnaire_infernal_1863_ocr.txt`: 1863년 제6판 전체 OCR 추출 텍스트 (앱 데이터 파싱 및 검색용)
